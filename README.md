
📌 Project Overview
This project focuses on deploying a PHP-based web application on a Linux server hosted on Amazon Web Services (AWS) EC2.
The project involves preparing the server environment, configuring a web server, setting up a database, and understanding how the different components work together to support a web application.

🎯 Objectives
* Understand the basics of cloud hosting using AWS EC2.
* Work with a Linux-based server environment.
* Configure Nginx to serve web application files.
* Set up PHP for server-side application processing.
* Prepare a MariaDB/MySQL database environment.
* Use Git and GitHub for project version control.

🛠️ Technologies Used
* Cloud Platform: AWS EC2
* Operating System: Ubuntu Linux
* Web Server: Nginx
* Backend Technology: PHP
* Database: MariaDB / MySQL
* Version Control: Git and GitHub

🏗️ Project Architecture
The application environment consists of the following components:
1. AWS EC2: Provides the virtual server to host the application.
2. Ubuntu Linux: Provides the operating system for the server.
3. Nginx: Receives HTTP requests and serves web content.
4. PHP: Processes server-side application logic.
5. MariaDB/MySQL: Stores and manages application data.
6. Git and GitHub: Help manage and document the project code.

⚙️ Implementation Steps
1. Launch an EC2 instance with Ubuntu Linux.
2. Connect to the instance using SSH.
3. Update the system package information.
4. Install and configure the required web server.
5. Install PHP and the required database packages.
6. Configure the database and application files.
7. Test the application through a web browser.
8. Upload the project code to GitHub.

🚀 Learning Outcomes
* Basic AWS EC2 instance management.
* Linux command-line operations.
* Web server installation and configuration.
* Introduction to PHP application hosting.
* Database setup fundamentals.
* Git and GitHub workflow.
